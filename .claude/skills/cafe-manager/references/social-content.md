# Reference — Social content (FB / IG / TikTok / Threads / Zalo)

> Đọc `_brand-voice.md` TRƯỚC. Reference này cho **format** + **template**, không bao tone.

## Workflow draft 1 post

1. Hỏi user (nếu thiếu):
   - **Platform**: FB / IG / TikTok / Threads / Zalo / multi
   - **Topic / SKU**: launch món mới, story nguyên liệu, behind-the-scenes, UGC, promo, dịp lễ, weather…
   - **Mục đích**: awareness / launch / sale / engagement / retention
   - **Ngày dự kiến post**
   - **Asset có sẵn**: ảnh / video / nothing (cần Canva/Higgsfield prompt)

2. Áp dụng template platform tương ứng (dưới)

3. Output structured như sau:

```
PLATFORM: <FB/IG/TikTok/Threads/Zalo>
PROPOSED POST DATE: YYYY-MM-DD HH:MM (best time per platform)
OBJECTIVE: <awareness/launch/...>
---
CAPTION:
<caption đầy đủ>

HASHTAGS:
<hashtag list>

ALT TEXT (IG bắt buộc):
<alt text>

CTA:
<câu CTA>

VISUAL BRIEF (cho user paste vào Canva/Higgsfield):
<prompt structured 50-100 từ — bao gồm: shot type, subject, color palette teal/coral/moss/cream, mood, mascot có/không, đoạn text overlay nếu có>

PUBLISHING NOTE:
<note ngắn cho user — vd "Post lên Story IG trước, feed sau 3h"; "Cần response sẵn 5 comment đầu"; "Cross-post Threads sau 2h">
```

## Template per platform

### FB template

```
[Hook 1 câu — quan sát/thời tiết/cảm giác]

[Body 2-3 câu — story/insight về drink/nguyên liệu/khách]

[CTA: ghé quán / inbox / đặt online]

[Tagline đóng]

#hashtag1 #hashtag2 #hashtag3 #hashtag4 #hashtag5
```

Length: 50-150 từ. Visual 4:5 hoặc 1:1.

**Ví dụ mẫu**:
> Mùa khô Lâm Hà vào sáng có nắng vàng nhạt, hơi se lạnh sót lại từ đêm.
> 
> Hôm nay かえる pha hojicha rang sâu thêm 30 giây — để khi tan vào sữa, vị khói trà bám lâu hơn trên đầu lưỡi. Mộc Châu sữa, Bảo Lộc trà. Một chuyến trở về trong 1 ly.
> 
> Mời bạn ghé sáng nay — chúng tôi mở từ 6 giờ.
> 
> *すべての一杯に、「おかえりなさい」を。*
> 
> #Mitsu #LâmHà #Hojicha #かえる #CàPhêLâmĐồng

### IG template

```
[Dòng 1 — hook trước "more" cut, có 0-1 emoji]

[Body 100-150 từ — micro-story, chi tiết về nguyên liệu/người làm/quá trình]

[Mời ghé + CTA cụ thể]

[Tagline JP + VN]

.
.
.
#hashtag1 #hashtag2 #hashtag3 #hashtag4 #hashtag5
#hashtag6 #hashtag7 #hashtag8 #hashtag9 #hashtag10
```

Cap caption tối đa 200 từ. Hashtag 8-12 đẩy xuống cuối qua 3 chấm.

**Alt text format**:
`[Loại drink/sản phẩm] [màu chủ đạo] [setting/đạo cụ] — [chi tiết mascot/nguyên liệu/người]`

VD: `Ly hojicha latte màu nâu mật trong cốc tre bên cửa sổ gỗ. Mascot かえる đứng cạnh đội nón lá. Ánh nắng sáng Lâm Hà.`

### TikTok template

**Cấu trúc 22-30s**:
- **0-3s**: Hook visual mạnh (rót trà cận, mascot xuất hiện, swirl)
- **3-15s**: Process / story / detail
- **15-22s**: Payoff (drink hoàn thiện, người uống thử, mascot smile)
- **22-30s**: CTA + tagline

**Caption < 100 từ**:
```
[1 câu hook khác hook video — không trùng]
[1 câu giá trị/CTA]

#hashtag1 #hashtag2 #hashtag3 #hashtag4 #hashtag5
```

**Sound**: ưu tiên original (ASMR pha trà + voice VN). Tránh trending pop không liên quan.

### Threads template

```
[1-3 câu conversational, không hashtag]

[Optional: câu hỏi mở mời cộng đồng]
```

Length 50-80 từ. Không hashtag (Threads không weight).

**Ví dụ**:
> Sáng nay Lâm Hà 18°C. Quán mới mở cửa — hơi nước từ ấm matcha bay lên cửa.
> 
> Mọi người uống gì lúc lạnh? Tôi đang phân vân giữa hojicha latte và bạc xỉu hot.

### Zalo OA template

```
[Tên khách nếu có] [Câu greeting ngắn]

[1 lý do — promo/SKU mới/dịp]

[CTA + link ngắn]

[Tagline ngắn]
```

Length 30-60 từ. KHÔNG hashtag. Compliance: chỉ gửi cho follower opt-in.

**Ví dụ**:
> Chào bạn 👋
> 
> Tuần này Mitsu có matcha 抹茶 mùa mới từ Bảo Lộc — chỉ pha 7 ngày đầu.
> 
> Ghé Lâm Hà thử nhé: mitsucafe.vn/menu
> 
> かえる đợi bạn 🍵

|---|---|---|---|
| Facebook | 7:30 | 11:30 | 19:30 |
| Instagram | 8:00 | 12:00 | 20:30 |
| TikTok | 12:00 | 19:00 | 21:00 |
| Threads | 9:00 | 14:00 | 22:00 |
| Zalo OA | 9:00 | 17:00 | (≤2/tuần) |

## Cadence khuyến nghị (tuần)

| Platform | Bài/tuần | Mix nội dung |
|---|---|---|
| FB | 3-5 | 40% product, 30% story, 20% UGC, 10% promo |
| IG feed | 4-5 | 30% product, 30% story, 20% behind-scenes, 20% UGC |
| IG Story | 7-14 | daily snapshot, polls, sticker |
| IG Reels | 1-2 | process / mascot / customer moment |
| TikTok | 2-3 | ASMR pha drink, mascot skit, day-in-life |
| Threads | 5-7 | conversational, daily observation |
| Zalo OA | ≤2 | promo / launch / event only |

## Cross-post matrix (tái dùng asset)

```
Source: TikTok 30s
  → IG Reels (same video, caption khác)
  → FB (cut 15s preview + link)
  → Threads (1 frame screenshot + text quote)
  → KHÔNG → Zalo OA (Zalo dành cho transactional)
```

```
Source: IG feed (photo + caption)
  → FB (caption shorter, hashtag fewer)
  → Threads (1 line từ caption)
  → KHÔNG re-post nguyên xi
```

## Khi user nói "draft 1 post nhanh"

Default assumption nếu user không nói:
- Platform: **IG** (hub của brand)
- Topic: 1 trong các SKU bestseller (`抹茶タロパール`, `ほうじ茶ラテ`, `バクシウ`)
- Post time: slot gần nhất từ giờ hiện tại
- Visual: cần Canva prompt (mặc định no asset)

Draft xong → hỏi: "Có muốn tôi adapt sang FB / TikTok / Threads không?"

## Anti-patterns (reject ngay)

- ❌ Caption copy-paste y hệt giữa 4 platform
- ❌ Hashtag bừa không phân loại
- ❌ CTA "Inbox ngay" không kèm lý do
- ❌ Quá 12 hashtag IG (spam signal)
- ❌ TikTok caption lặp lại 100% lời trong video
- ❌ Threads dùng hashtag
- ❌ Zalo OA broadcast >2 lần/tuần
